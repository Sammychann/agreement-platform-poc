    Phase 4 Module

    Customer Folder Completeness Scanner

    Scans customer audit directories to ensure each customer folder contains all 4 mandatory business files.

    1. Agreement PDF

    Signed commercial agreement or contract document (*agreement*.pdf)

    2. Installation Report PDF

    Field engineer commissioning and handover protocol (*installation*.pdf)

    3. Approval Mail PDF

    Management & finance deal approval record (*approval*.pdf / .eml)

    4. Finance Excel File

    Commercial pricing sheet or billing schedule (*finance*.xlsx)

    Python Module Architecture (folder_validation.py)

    # Available function ready for implementation:
from folder_validation import validate_customer_folder, scan_parent_directory

report = validate_customer_folder("Customer_A/")
# If all 4 files present -> 'COMPLETE'
# If missing Approval Mail -> 'INCOMPLETE - Missing: Approval Mail PDF'
